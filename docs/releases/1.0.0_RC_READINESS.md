## Blocking owner decision — license

The repository currently has no `LICENSE` file and `pyproject.toml` does not declare a
license.

The project release strategy requires the package license to be defined before public
publication. The hardening phase intentionally did not invent this legal/product-owner
choice.

T21-014 must therefore not promote `1.0.0rc1` until the project owner chooses the license
policy.

Examples of possible owner decisions include:

```text
MIT
Apache-2.0
another open-source license
proprietary / all-rights-reserved policy
```

The implementation should follow the chosen policy by adding the appropriate license file
and package metadata; it must not infer one from the repository being public.

## RC action after blocker resolution

Once the license policy is chosen:

```text
license file + metadata
        ↓
1.0.0rc1 version bump
        ↓
README / CHANGELOG release promotion
        ↓
full CI qualification
        ↓
immutable RC tag/release
        ↓
RC freeze: fixes/docs/qualification only
```

Any code correction after RC1 qualification requires RC2 before stable promotion.
