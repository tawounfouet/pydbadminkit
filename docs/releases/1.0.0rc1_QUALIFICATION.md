# PyDBAdminKit 1.0.0rc1 Qualification

## Promotion

```text
Version: 1.0.0rc1
Stage: Release Candidate
License: Apache-2.0
Feature state: FROZEN
```

The RC source is promoted after LOT-20 and T21-001 through T21-013 qualification and
documentation work.

## Required gates

```text
Quality
Unit Tests — Python 3.11, 3.12, 3.13, 3.14
PostgreSQL Integration — PostgreSQL 14, 15, 16, 17, 18
Package — wheel + sdist install on Python 3.11–3.14
```

The RC is qualified only when every job is green.

## RC freeze

No new feature is permitted between RC and stable. Allowed changes are bug fixes,
security/safety fixes, documentation, qualification and release metadata.

Any code correction after RC1 qualification requires a new RC number before stable
promotion.

## Stable promotion rule

`1.0.0` must contain no new functionality relative to the final qualified RC.
